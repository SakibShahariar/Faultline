Memory pressure — process terminated

8 November 2026 · Previous boot · Incident #FL-003
High severity

Memory pressure likely contributed to the system becoming unresponsive.

Confidence: High · Evidence-based assessment, not a confirmed root cause

What Faultline found

OOM killer activity detected. The kernel terminated a memory-heavy process shortly before the last recorded system activity. This supports memory pressure as a contributing factor, but does not prove it caused the shutdown.
